# ScreenMatch

ScreenMatch é uma aplicação Java que permite pesquisar filmes e obter informações como nome, URL do pôster e ano de lançamento. O projeto é uma ótima prática para manipulação de APIs, uso de classes Java modernas e gerenciamento de dados em JSON.

## Funcionalidades

- Pesquisar filmes pelo nome
- Retornar nome, URL do pôster e ano de lançamento
- Manipulação de dados em JSON utilizando Gson
- Estrutura organizada em pacotes e classes

## Tecnologias Utilizadas

- Java
- Gson (para manipulação de JSON)
- Maven (ou Gradle, se preferir)
- IDE recomendada: IntelliJ IDEA ou Eclipse
